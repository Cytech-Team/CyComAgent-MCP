# Unified Cross-Platform Build and Release

CyComAgent uses one source tree and one release orchestrator. Platform-specific
service integration and packaging remain adapters; they are not separate Core
versions.

## Commands

```bash
./cycom detect       # identify host OS and architecture
./cycom build        # build the current supported host target
./cycom build --all  # cross-build every currently supported target
./cycom test         # run Go tests and vet
./cycom release      # test, build, package and checksum all supported targets
```

`./cycom release` is a local packaging operation. It does not commit, push,
create tags, or publish a GitHub Release. Pushing a `v*` tag runs
`.github/workflows/release.yml`, which builds the packages and attaches all
files under `dist/` to that tag's GitHub Release.

## Current target matrix

| Platform | Target | Delivery | Status |
| --- | --- | --- | --- |
| Linux | amd64 | Core + root broker + systemd installer | Supported |
| Android / Termux | arm64 | non-root mobile_assistant Core + runit + Termux installer | Supported |
| macOS | arm64, amd64 | shared Core + LaunchAgent installer | Experimental |
| Windows | amd64/arm64 | PowerShell-native bridge package | Bridge only; no shared Core binary |
| Android native app | arm64 | APK / native app | Not implemented; Termux is a separate target |
| iOS | device architectures | signed native app | Not implemented; requires an iOS app target, signing and distribution pipeline |

A platform can be detected without implying that it is a supported build
artifact. The orchestrator exits with a clear message for unsupported native
Android and iOS app packaging rather than generating a misleading binary.

## Release safety

- Release assets are built from the same Git revision in GitHub Actions.
- Android/Termux is built with `GOOS=android GOARCH=arm64`.
- macOS targets are built separately for Apple Silicon and Intel.
- Windows currently ships its native PowerShell bridge, not a fake Go Core binary.
- Checksums are generated by the existing platform packaging targets.
- Linux/root and Android binaries are published as `cycomagent-*` sync assets with
  `SHA256SUMS-sync`, which the startup updater verifies before replacing anything.
- The local `release` command never mutates Git history or publishes remotely.
